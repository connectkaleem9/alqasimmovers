# Content Strategy

Project: Al Qasim Movers — movers & packers, Dubai (https://alqasimmovers.com). Follow `CLAUDE.md` and the rules in `.claude/rules/`, especially `content-integrity-rules.md`.

## Instructions
1. For each proposed page, run the five-question test from `.claude/rules/seo-rules.md`.
2. Define the page's job in the funnel (learn → compare → decide → contact).
3. Outline sections from the SEO brief; each section must answer a real user question.
4. For blog posts, name the commercial page each article supports and link to it.
5. Add or update the row in `docs/seo/content-calendar.md`.

## Checklist
- [ ] Five-question test passed and recorded
- [ ] Outline answers real questions
- [ ] No overlap with an existing page
- [ ] Commercial link target set (blog)
- [ ] Calendar updated

## Expected Output
Approved outline in the SEO brief + content-calendar row.
