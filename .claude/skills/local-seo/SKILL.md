# Local Seo

Project: Al Qasim Movers — movers & packers, Dubai (https://alqasimmovers.com). Follow `CLAUDE.md` and the rules in `.claude/rules/`, especially `content-integrity-rules.md`.

## Instructions
1. Confirm NAP from `config/business.json`; use the exact same format everywhere.
2. Area page validation — create only if ALL are true: owner confirms area is served (all of Dubai is confirmed); ≥ 4 genuinely area-specific points (property types, access/parking/loading realities, building/community rules, typical moves); unique FAQs; not a near-duplicate of another area page.
3. Map service ↔ area relationships (which services matter most in which areas) for internal linking.
4. GBP: none exists (owner decision 2026-09-19). Keep the site GBP-ready. If a GBP is created later, name, phone, categories, service areas, website URL and hours must match the site.
5. Build a citation list (reputable UAE directories); no spammy directories.
6. Review strategy: owner asks real customers for Google reviews after jobs. No incentives that breach Google policy, no fake reviews.

## Checklist
- [ ] NAP identical everywhere
- [ ] Every area page has a documented validation decision
- [ ] GBP alignment checklist complete
- [ ] Citation list sourced
- [ ] Review process defined with owner

## Expected Output
`docs/seo/local-seo-strategy.md` including the Area Validation table.
