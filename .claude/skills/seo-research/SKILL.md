# Seo Research

Project: Al Qasim Movers — movers & packers, Dubai (https://alqasimmovers.com). Follow `CLAUDE.md` and the rules in `.claude/rules/`, especially `content-integrity-rules.md`.

## Instructions
1. Search the query as a Dubai user would (google.ae, English). Note SERP features: Local Pack, ads, PAA, videos, directories.
2. Classify the dominant intent of the top 10: service page, directory/aggregator, blog, homepage.
3. Record the page types and depth of the top 5 organic results (do not copy content).
4. Note questions users ask (PAA, related searches).
5. Decide: does a page on our site fit this intent? Which URL?

## Checklist
- [ ] Query, date, and location recorded
- [ ] SERP features listed
- [ ] Dominant intent stated with evidence
- [ ] Top-5 page-type summary
- [ ] Recommendation: target URL or 'no page'

## Expected Output
A short section in the relevant SEO brief or `docs/seo/serp-notes.md`: query → intent → page type → recommendation.
