# Ui Ux Design

Project: Al Qasim Movers — movers & packers, Dubai (https://alqasimmovers.com). Follow `CLAUDE.md` and the rules in `.claude/rules/`, especially `content-integrity-rules.md`.

## Instructions
1. Define brand direction from research: audience, tone, what 'trustworthy and local' looks like here.
2. Define tokens: colour (with contrast ratios), type scale, spacing scale, radii, shadows, breakpoints.
3. Specify components: buttons, cards, forms, icons, header, footer, mobile nav, hero, sections, breadcrumbs, review card, project card, FAQ accordion, sticky CTA bar.
4. Wireframe mobile first: home, service template, area template, blog post, contact/quote.
5. Review against design and accessibility rules; get owner feedback.

## Checklist
- [ ] Tokens defined
- [ ] AA contrast verified for all text/UI pairs
- [ ] All required components specified
- [ ] Mobile + desktop wireframes
- [ ] Design review passed
- [ ] Owner feedback recorded

## Expected Output
`docs/design/design-system.md` + `docs/design/wireframes/*`.
