## Five-question test
1. **Search intent satisfied:** Visitors and regulators checking how data is handled.
2. **Why this page deserves to exist:** Required for the forms and for Google Analytics consent; describes actual behaviour.
3. **Unique information it provides:** see the H2 outline below.
4. **Action the user should take:** request a quote, call, or WhatsApp.
5. **Internal pages it connects to:** the related-links block at the foot of the page.

## Targeting

- **Primary (AR):** سياسة الخصوصية
