# Al Qasim Movers — Website

Website for **Al Qasim Movers**, movers & packers in Dubai, UAE — https://alqasimmovers.com

- Phone: 0556869224 (+971 55 686 9224)
- Stack: static HTML5 + CSS3 + vanilla JavaScript, zero-dependency Node build
- Goal: Local SEO, organic traffic, lead generation

## Start here
1. `CLAUDE.md` — project rules and how Claude works on this repo
2. `PROJECT_MEMORY.md` — current status and next task
3. `docs/roadmap.md` — stages 1–14
4. `docs/owner-questions.md` — information needed from the business owner

## Layout
- `.claude/` — agents, skills, rules
- `config/business.json` — single source of business facts
- `docs/` — research, SEO, design, architecture, audits
- `src/` — website source (from Stage 4)
- `scripts/` — build and QA scripts (from Stage 4)
- `dist/` — build output / deployable site (git-ignored)

## Build (available from Stage 4)
```
node scripts/build.mjs
```
